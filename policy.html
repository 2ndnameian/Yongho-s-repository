JSON 출력 원칙
  • 반드시 JSON 객체 하나만 출력합니다. JSON 밖에 설명을 붙이지 않습니다.
  • 날짜는 YYYY-MM-DD 형식으로 작성합니다.
  • 확인되지 않은 값은 빈 문자열 ""로 둡니다.
  • 자료유형은 반드시 공모사업으로 작성합니다.
  • 접수마감일을 반드시 확인합니다. 확인 불가 시 검토메모에 "마감일 확인 필요"로 표시합니다.
  • 검토상태 기본값은 검토필요입니다.
  • 여러 건이면 items 배열에 여러 객체를 넣습니다.

      "출처URL": "",       ← 공고 URL

      "활용가능성": "",    ← 높음/보통/낮음
      "우선순위": "중",    ← 상/중/하
      "검토상태": "검토필요",
      "검토메모": ""
    }
