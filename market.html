JSON 출력 원칙
  • 반드시 JSON 객체 하나만 출력합니다. JSON 밖에 설명을 붙이지 않습니다.
  • 날짜는 YYYY-MM-DD 형식으로 작성합니다.
  • 확인되지 않은 값은 빈 문자열 ""로 둡니다.
  • 자료유형은 반드시 정책으로 작성합니다.
  • 발표일을 우선 확인합니다.
  • 검토상태 기본값은 검토필요입니다.
  • 여러 건이면 items 배열에 여러 객체를 넣습니다.
{
  "조사일": "YYYY-MM-DD",
  "조사도구": "Claude",
  "조사주제": "조사 주제 내용",
  "items": [
    {
      "자료유형": "정책",
      "제목": "",          ← 정책명
      "기관": "",          ← 발표 기관
      "발표일": "",        ← 발표일 (YYYY-MM-DD)
      "출처URL": "",       ← 정책 공고 URL
      "핵심내용": "",
      "정책시사점": "",    ← 과정개발·기관운영·훈련시장 변화 연결
      "활용가능성": "",    ← 높음/보통/낮음
      "권장액션": "",      ← 우리 기관이 확인하거나 준비할 일
      "검토상태": "검토필요",
      "검토메모": ""
    }
  ]
}
