🤖 Claude 조사 도우미

Claude에게 조사를 지시하고, 결과를 Notion 수집 DB에 바로 넣을 수 있는 고정 JSON 형식으로 받아보세요.
아래 순서대로 사용하면 됩니다.

① 조사 주제 입력 → ② 지시문 생성·복사 → ③ Claude에게 붙여넣기 → ④ 결과 JSON 검토 → ⑤ Notion 반영
1
조사 설정 — 자료유형과 주제를 입력하면 Claude 지시문을 자동으로 만들어 드립니다
✓
Claude 조사 지시문 — 아래 내용 전체를 복사해서 Claude 대화창에 붙여넣으세요
💡 이 지시문을 그대로 Claude에게 주면, Notion에 바로 넣을 수 있는 고정 JSON으로 조사 결과를 받을 수 있습니다.
2
Claude 출력 원칙 — Claude가 반드시 지켜야 하는 JSON 작성 규칙입니다
📦JSON 객체 하나만 출력합니다. JSON 밖에 설명·말을 붙이지 않습니다.
🗂자료유형은 정책, 공모사업, 뉴스, 경쟁기관 중 정확히 하나로만 작성합니다.
🔗출처URL은 반드시 작성합니다. 공식 출처가 없으면 빈 문자열("")로 표기합니다.
📅날짜는 YYYY-MM-DD 형식으로 작성합니다. (예: 2026-05-07)
✅검토상태 기본값은 "검토필요"로 고정합니다. 임의로 바꾸지 않습니다.
🤖조사도구는 "Claude"로 고정합니다.
❓확인되지 않은 값은 빈 문자열("")로 작성합니다. 임의로 채우지 않습니다.
📊활용가능성·우선순위는 "상", "중", "하" 중 하나로만 작성합니다.
📄 JSON 출력 구조 예시 공모사업 1건 기준
{ "조사일": "2026-05-07", "조사도구": "Claude", "조사주제": "직업훈련 공모사업 조사", "items": [ { "자료유형": "공모사업", "제목": "예시 공모사업명", "기관": "예시 기관", "발표일": "2026-05-01", "접수마감일": "2026-05-31", "출처URL": "https://example.com/notice", "원문URL": "https://example.com/file.pdf", "핵심내용": "직업훈련기관을 대상으로 신규 과정 운영을 지원하는 공모사업이다.", "직업훈련관련성": "국비훈련 과정개발 및 기관 운영 전략과 직접 관련된다.", "활용가능성": "상", "정책시사점": "", "공모기회": "참여요건 확인 후 제안서 작성 여부를 검토할 수 있다.", "시장변화": "", "경쟁기관동향": "", "권장액션": "공고문 원문 확인 후 참여 가능 여부를 1차 판단한다.", "우선순위": "상", "검토상태": "검토필요", "검토메모": "" } ] }
3
Notion 반영 기준표 — Claude JSON 항목 → Notion DB 필드 연결 기준
📌 Claude가 출력한 JSON 항목이 Notion DB의 어느 필드에 연결되는지 보여줍니다. 자료유형 탭을 선택해서 확인하세요.
4
조사 결과 검토 — Claude 결과 JSON을 붙여넣고 Notion 반영 전 필수 항목을 확인합니다
💡 Claude가 출력한 JSON을 그대로 붙여넣으면, 누락 항목·형식 오류를 자동으로 점검해 드립니다. 통과 판정이 나야 Notion에 반영하세요.
